# LinkedIn Post

Publiqué mi primer proyecto de portafolio de Data Analytics:

**Análisis de oferta musical en México con Ticketmaster API**

En este proyecto construí un flujo completo de análisis de datos usando datos de eventos musicales disponibles en Ticketmaster México.

El proceso incluyó:

- Extracción de datos desde la Ticketmaster Discovery API
- Limpieza y normalización con Python
- Preparación de datasets para Power BI
- Creación de un dashboard interactivo
- Documentación del proyecto en GitHub

Algunos hallazgos:

- Ciudad de México concentra la mayor parte de la oferta musical analizada
- Monterrey y Zapopan aparecen como mercados relevantes después de CDMX
- Los géneros con mayor presencia son Latin, Pop y Rock
- Venues como Auditorio Nacional, Teatro Metropolitan y Palacio de los Deportes concentran un volumen importante de eventos

Este proyecto me ayudó a practicar un flujo real de trabajo:

**API → Python → CSV limpio → Power BI → storytelling → GitHub**
